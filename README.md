# Xiaomi Market as System App (KernelSU Module)

Turn the **China Xiaomi App Store** (`com.xiaomi.market`) into a **system app** on
**global HyperOS / MIUI ROMs**, restoring its **silent install** capability.

The store APK is **bundled** (`apk/com.xiaomi.market.apk`, version `4.130.s.00`),
so you can flash and go.

> Tested on Xiaomi HyperOS `3.0.301.0.WOLTWXM` (global), Android 16, KernelSU.

---

## Install

1. **Remove or disable any other module that also provides `com.xiaomi.market`**
   (for example modules generated by "爱玩机工具箱" / other "convert to system app" tools).
   Two modules mounting the same path will conflict.

2. Download `miui_market_cn.zip` from [Releases](../../releases) and flash it:

   ```
   KernelSU -> Modules -> Install from storage -> miui_market_cn.zip
   ```

   (Or build it yourself — see [Build](#build).)

3. Reboot.

4. Open the store, sign in, install any app — it should install **without a confirmation dialog**.

---

## Why this works

Silent install needs **two** things:

| Requirement | Status on a global ROM |
|---|---|
| `INSTALL_PACKAGES` permission | Already granted — the APK is signed with Xiaomi's own certificate (`CN=MIUI, O=Xiaomi`), and the ROM grants signature-level permissions listed in `signature-permissions-miui-system.xml`. |
| **System-app identity** | **Missing** — this is what the module fixes. |

The store checks its own install location:

```
codePath = /data/app/...    -> "user-installed" -> normal install flow (asks the user to confirm)
codePath = /system/...      -> "preinstalled"   -> silent install
```

Installing the APK the normal way puts it in `/data/app`; even with `flags=[SYSTEM]`
the code path is still `/data`, so the store falls back to the regular install flow.

`/system` is **erofs (read-only)**, so you cannot copy files into it. The module uses
KernelSU's overlay (magic mount) to present the APK at `/system/app/com.xiaomi.market/`
at boot. PackageManager then scans it as a preinstalled app.

## Module layout

```
system/app/com.xiaomi.market/
├── com.xiaomi.market.apk
└── lib/
    ├── arm64/*.so      (from APK lib/arm64-v8a)
    └── arm/*.so        (from APK lib/armeabi-v7a)
```

The native libraries **must** be present: the APK declares `extractNativeLibs=true`,
and when it is scanned as a system app the loader looks for its `.so` files in
`app_dir/lib/<abi>/`. Missing them causes a crash at launch.

## Build

The repository already ships the APK, so no arguments are needed:

```bash
./tools/build.sh                     # -> miui_market_cn.zip
powershell -ExecutionPolicy Bypass -File .\tools\build.ps1
```

With a newer store version:

```bash
./tools/build.sh /path/to/newer.apk my_build.zip
powershell -ExecutionPolicy Bypass -File .\tools\build.ps1 -Apk C:\path\to\newer.apk
```

## Verify

```bash
adb shell pm path com.xiaomi.market
# package:/system/app/com.xiaomi.market/com.xiaomi.market.apk

adb shell dumpsys package com.xiaomi.market | grep -E 'codePath|flags'
# codePath=/system/app/com.xiaomi.market
# flags=[ SYSTEM HAS_CODE ALLOW_CLEAR_USER_DATA LARGE_HEAP ]

adb shell dumpsys package com.xiaomi.market | grep -E 'INSTALL_PACKAGES:|DELETE_PACKAGES:'
# android.permission.INSTALL_PACKAGES: granted=true
# android.permission.DELETE_PACKAGES: granted=true
```

## Updating the store

The store updates itself in place — but if you want a newer **system** copy
(for example after a clean flash):

1. Replace `apk/com.xiaomi.market.apk` with the new APK (or pass it via `-Apk` / `$1`).
2. Rebuild the zip.
3. Reflash in KernelSU and reboot.

App data (login, download history) is kept as long as the signature is unchanged.

## Troubleshooting

### The package is not recognized at all

Symptom:

```
adb shell pm path com.xiaomi.market      # empty
logcat: Couldn't determine stopped state for unknown package: com.xiaomi.market
```

Cause: **wrong SELinux label**. If the module files were copied from `/data/local/tmp`
(via `adb push` + `cp`), they inherit `u:object_r:adb_data_file:s0`, which
`system_server` cannot read, so PackageManager silently skips the APK.

Check:

```bash
adb shell su -c 'ls -Z /system/app/com.xiaomi.market/com.xiaomi.market.apk'
# must be: u:object_r:system_file:s0
```

Fix (the module does this automatically in `post-fs-data.sh`):

```bash
adb shell su -c 'chcon -R u:object_r:system_file:s0 /data/adb/modules/miui_market_cn/system'
```

Then reboot.

### The store opens but still asks for confirmation

* Make sure no `/data/app` copy exists: `adb shell pm uninstall com.xiaomi.market`
  (reverts to the system base; data may be kept depending on the ROM).
* Check `codePath` — it must be under `/system/app`, not `/data/app`.

### Boot loop after flashing

Disable the module from recovery or adb:

```bash
adb shell su -c 'touch /data/adb/modules/miui_market_cn/disable'
```

or delete `/data/adb/modules/miui_market_cn`.
